General Guidelines

Objectives of the Lab

  • Understand and implement fundamentals of HTML, CSS, JavaScript and modern web technologies.
  • Design and develop responsive, interactive web pages and applications.
  • Implement client-side scripting, DOM manipulation, events, forms and validation.
  • Design and implement open-ended web applications using concepts learned.

Structure of Experiments

First group: HTML and CSS pages. Second group: JavaScript interactive applications. Subsequent experiments cover Bootstrap, React and other modern concepts. The final open-ended experiment is a complete web application built without direct faculty assistance; its problem statement is not in the manual.

General Lab Information

  • Lab manuals/data sheets are the primary source for continuous evaluation; fill them in and number pages properly.
  • Students may work in a batch, but each must individually explain the objective, algorithm, code and working.
  • Maintain additional notes (details, observations, errors, corrections); these may be evaluated.
  • Remain in the lab until the end of the 2-hour session.

Note: Prepare before each lab. Within the first 30 minutes, independently write the aim, requirements, algorithm/steps, basic code structure and expected output in the data sheet.

Course Objectives

  1. Fundamentals of web development; HTML for structured pages with tables and forms.
  2. CSS for styling, layouts, text formatting and responsive design.
  3. JavaScript and React for interactive apps, DOM manipulation and components.
  4. Responsive, user-friendly interfaces with Bootstrap and basic UI/UX principles.

Modules

  • Module 1 – Intro to Web Development and HTML (3 h): Static vs dynamic websites, front-end, back-end, full stack, Internet basics, HTML syntax, semantic markup, document structure, elements, tables and forms.
  • Module 2 – CSS Basics (2 h): Syntax, location of styles, selectors, text styling, font, background, border.
  • Module 3 – CSS Advanced (2 h): The cascade, links, tables, forms, box model, images, responsive images, layouts, specificity, units.
  • Module 4 – JavaScript and React (6 h): Functions, arrays, objects, ES6 (arrow functions, destructuring, spread), DOM and events, components, JSX, props, state, hooks (useState, useEffect), React Router.
  • Module 5 – Bootstrap and UI/UX (2 h): Grid, responsive design, components, forms, buttons, navigation, cards, modals, carousel, overview of Figma.

Course Outcomes

  1. Build structured web pages with HTML including tables and forms.
  2. Apply CSS for appealing, well-structured, responsive designs.
  3. Develop interactive apps with JavaScript and React (events, DOM, components).
  4. Design responsive apps with Bootstrap and intuitive UI/UX with tools like Figma.

  8. Add an <article>.
  9. Add an <aside> for resources.
  10. Insert an image with <img>.
  11. Add hyperlinks with <a>.
